  The two runs returned THE SAME allocation. That is not a coincidence and it
  is a genuinely useful finding: the applicant-optimal and the centre-optimal
  stable matchings are the extreme points of the lattice of stable matchings,
  so when they coincide the instance has EXACTLY ONE stable matching. Our
  criteria-derived preferences are strongly correlated (nearly every hawker
  ranks the high-footfall Maxwell and Old Airport Road first), and correlated
  preferences collapse the lattice to a single point.
  A data set therefore has to be built deliberately to show the proposer's
  advantage - which is what the next exercise does.

    Both allocations are stable: blocking pairs = 0 and 0.
  => the proposing side is never worse off. If hawker welfare is the
     objective, the NEA should run the exercise hawker-proposing.
